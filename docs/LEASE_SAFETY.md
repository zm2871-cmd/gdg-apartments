# Lease processing and safety

The initial rule registry is `src/lib/legal/rules.ts`, version 2026-10-29. Official source: https://ag.ny.gov/publications/residential-tenants-rights-guide, accessed during implementation. Three topic screens: late-fee/grace-period language, security deposits, and repair/habitability waivers. The source is verified as official guidance; the screening logic is **not counsel-approved**. No fabricated statutory citations or legal verdicts are emitted.

Every result includes an exact extracted excerpt, page, fixed curated source ID, jurisdiction and suggested question. All flags currently use `needs_review`, including benign clauses mentioning the topic. Therefore the evaluation measures topic detection/grounding, not legal-risk precision/recall. 22 annotated synthetic clauses achieve expected topic counts in tests; every returned quote must be an actual substring and reference a registered rule. A prompt-injection example creates no result and is never executed.

Upload flow: authenticated user + consent; PDF MIME/magic/size validation; real page-by-page PDF.js extraction; page/text caps; reject image-only or encrypted/unreadable documents; private random UUID storage key; owner RLS. Analysis is an explicit action on the uploaded document and can be retried. PDF and exact finding excerpts expire after 30 days. Storage is deleted first, then the parent record with cascades. No public document URL or external document AI call is created.

Known limits: clause segmentation is punctuation-based, cannot reliably distinguish negation/conditional exceptions, and is not an enforceability classifier. Mixed scanned/text PDFs may leave unreadable pages unscreened; no OCR or coordinate highlighting exists. Original PDFs are not displayed inline; anchored excerpts are shown. Vercel body limits may restrict uploads below 10 MB; implement private direct upload initiation before advertising full 10 MB support there. Cleanup is capped at 50 documents/run and needs operational alerts. Extractor CPU/memory isolation and distributed abuse limits remain launch-hardening tasks.

No document-analysis access or deletion claim has been verified against a provisioned Supabase instance in this session. Run the supplied RLS test and storage lifecycle integration tests before enabling public uploads. Qualified counsel must review rule applicability, wording, disclosures and retention policy before launch.
